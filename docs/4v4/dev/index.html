          使い方

          4v4 の試合を、スマホで記録するためのアプリです。得点は 2点・3点で入力し、得点した時間はタイマーから自動で記録します。

          1. チーム・メンバーを登録（任意）: 「チーム」タブでメンバーを登録し、チームを作って所属メンバーを選びます。1人が複数のチームに入れます。
          2. 出場チーム・メンバーを選ぶ: 「試合」タブで自分側・相手側のチームを選びます。チームのメンバー（6人まで）が出場メンバーになります。
          3. 試合を始める: 「開始」でカウントダウン（既定10分）が始まります。得点したら「+2」「+3」を押します。間違えたら「直前の得点を取り消す」か、得点の履歴の行をタップして直します。
          4. 交代の通知: 既定は5分ごと。交代の15秒前と交代の時刻に、音・振動・画面で知らせます。時計の下のボタンで間隔を変えたり、オフにしたりできます。
          5. 試合を終える: 「試合終了」で結果を履歴に保存します。「履歴」タブで成績の確認、試合の修正・削除、記録し忘れた試合の手入力ができます。

          よくある質問

          ホーム画面に追加できますか？
          できます。iPhone は Safari の共有ボタンから「ホーム画面に追加」、Android は Chrome のメニューから「ホーム画面に追加」を選んでください。アプリのように開けます。
          交代の通知が出ません
          このアプリは Web アプリのため、画面をロックしたり別のアプリを長く使ったりすると、タイマーが止まって通知が出ないことがあります。試合中は画面を点けたまま使ってください（試合中は自動で消灯しないようにしています）。マナーモードでは音が出ないことがあり、iPhone では振動しません。
          端末の通知（通知センター）に出したい
          試合画面の「端末の通知を許可する」から許可してください。iPhone はホーム画面に追加して開いた場合だけ使えます。
          記録はどこに保存されますか？
          お使いの端末のブラウザの中だけです。ほかの端末やブラウザとは共有されません。
          記録を全部消したい
          「履歴」タブの一番下の「試合データをすべて削除」で、終了した試合をまとめて消せます。チーム・メンバーは「チーム」タブから1件ずつ削除できます。

          プライバシーポリシー
